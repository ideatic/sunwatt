随时查看您的光伏发电量和电价。SunWatt 在小组件、锁定屏幕、控制中心和您的 Apple Watch 上显示两者。支持华为 FusionSolar、SolarEdge 和 PVOutput。

免费。无需账户，无追踪，无广告。

光伏
连接您的光伏系统，查看当前功率（kW）、今日发电量（kWh）和今日发电曲线。SunWatt 支持：
• 华为 FusionSolar：粘贴您的 Kiosk 链接，或输入安装商为您创建的 API 账户
• SolarEdge：输入您的站点 ID 和 API 密钥
• PVOutput：输入您的系统 ID 和 API 密钥。PVOutput 支持许多逆变器品牌，例如 Fronius、SMA、Enphase、GoodWe 和 Growatt
• Fronius：输入逆变器在家庭网络中的地址（仅在家中时可获取数据）
• 一个应用管理多座光伏电站
• 可选的家中实时数据：通过 Modbus TCP 在家庭网络中读取华为智能通信棒或 SunSpec 逆变器（只读）
引导页会用几分钟时间告诉您每一项在哪里找到。

电价
• 西班牙：Red Eléctrica 提供的受监管 PVPC 电价
• 葡萄牙、法国、德国和卢森堡、奥地利、比利时、荷兰和意大利北部：日前批发电价
• 当前电价按价格水平着色，一眼就能看出便宜还是昂贵
• 今日电价图表和即将到来的最便宜时段
• 明日电价一经公布即可查看

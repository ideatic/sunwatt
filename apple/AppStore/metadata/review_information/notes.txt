SunWatt - notes for App Review

No login. The app has no accounts and no sign-in screen. Nothing to enter except optional solar details (see below).

What the app does
SunWatt shows widgets with (1) the electricity price and (2) the output of a home solar plant. For solar, the user picks one provider under "Solar system": Huawei FusionSolar (kiosk link), SolarEdge (site ID + API key from the SolarEdge monitoring portal) or PVOutput (system ID + API key from pvoutput.org; many inverter brands upload to PVOutput). The price part works with no setup.

How to test the solar part (demo plant)
We give you a read-only Huawei FusionSolar kiosk link of the developer's own home solar plant. It is at the end of these notes, under "Demo kiosk link". It shows live production only (no account, no control over the plant). Please do not share it.
1. Open the app. Tap "Get started" on the welcome page.
2. Choose a country (for example Spain, or any other in the list) and continue.
3. On the "Solar production" page choose Huawei FusionSolar, paste the demo kiosk link in "Kiosk link" and tap "Test connection". It shows "Connected". Finish the onboarding.
4. The dashboard shows today's solar curve and energy, plus the current price, today's price chart and the cheapest upcoming hours. Tomorrow's prices appear later in the day, when the data provider publishes them. At night the plant produces 0 kW; this is expected.
5. Add a widget: touch and hold the Home Screen, tap "Edit" > "Add Widget", search "SunWatt". Choose small, medium or large; the widget shows solar and price. Lock Screen widgets and the Control Center controls can be added the same way.
6. Tap a widget: the app opens and loads fresh data, and the widgets update.
7. Siri / Shortcuts: say "What's the electricity price in SunWatt?".
8. On the Mac, the gear button in the toolbar opens Settings ("Solar system").
Huawei kiosk links can expire. If the link stops working, write to contacto@ideatic.net and we send a new one at once.

How to test without a solar plant
The solar part is optional. On the "Solar production" page tap "Skip, prices only", then finish the onboarding. In the widget settings choose "Price".

With no solar system set up, the solar widgets show a short message that solar is not set up. This is expected.

Network and data
The app contacts only:
- apidatos.ree.es (Red Eléctrica, public PVPC prices for Spain)
- api.energy-charts.info (Energy-Charts, Fraunhofer ISE, CC BY 4.0, day-ahead prices for other countries)
- the FusionSolar server named in the kiosk link the user pastes (only if the user chooses FusionSolar)
- monitoringapi.solaredge.com (official SolarEdge Monitoring API, HTTPS; only if the user chooses SolarEdge)
- pvoutput.org (PVOutput API, HTTPS; only if the user chooses PVOutput)
The app has no API keys of its own. A SolarEdge or PVOutput API key is entered by the user, is sent only to that provider, and is stored only on the device (in the keychain, shared with the widgets, and synced to the user's own Apple Watch). No tracking, no analytics, no ads. Nothing is sent to the developer. Settings and last data are stored on the device (App Group shared with the widgets).

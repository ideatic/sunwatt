太陽能
連接您的太陽能光電系統，即可查看目前功率（kW）、今日發電量（kWh）與今日發電曲線。SunWatt 支援以下系統：
• 華為 FusionSolar：貼上您的 Kiosk 連結，或輸入安裝商為您建立的 API 帳號
• SolarEdge：輸入您的站點 ID 與 API 金鑰
• PVOutput：輸入您的系統 ID 與 API 金鑰。PVOutput 支援多種變流器品牌，例如 Fronius、SMA、Enphase、GoodWe 與 Growatt
• Fronius：輸入變流器在家中網路上的位址（僅在家中時可取得資料）
• 一個應用程式可管理多座太陽能電站
• 選用的家中即時資料：透過家中網路讀取華為 Smart Dongle 或 SunSpec 變流器（Modbus TCP，唯讀）
新手導覽會在幾分鐘內告訴您每項設定的位置。

電價
• 西班牙：Red Eléctrica 提供的受管制 PVPC 電價

• 依價位高低以顏色標示目前電價，一眼就能看出電價便宜或昂貴
• 今日電價圖表與接下來最便宜的時段
• 明日電價一經公布即顯示

向 Siri 詢問目前電價、目前太陽能發電量，或最便宜的時段。您也可以在自己的捷徑與自動化中使用這些功能，例如在電價便宜時啟動洗碗機。

Privacy Policy

App: SunWatt (iPhone, iPad, Mac, Apple Watch). Last updated: 17 October 2026.

Short version. SunWatt has no account, no tracking, no analytics and no ads. Nothing is sent to the developer.

Who we are

SunWatt is published by ideatic Development, S.L.U. (Spain). Contact: REPLACE-ME@example.com.

Data we collect

None. We do not collect, receive or store any personal data. We have no servers for the app.

Network connections

The app contacts only these servers, to get the data it shows:

  • The Huawei FusionSolar server named in the kiosk link you paste (only if you add a link), to read your plant data.
  • The Huawei FusionSolar server you enter for a FusionSolar API account (only if you set one up, a fusionsolar.huawei.com address), to read your plant data. Your user name and system code are sent to it over HTTPS.
  • monitoringapi.solaredge.com (the official SolarEdge Monitoring API, only if you set up SolarEdge), to read your plant data. Your site ID and API key are sent to SolarEdge over HTTPS.
  • pvoutput.org (the PVOutput API, only if you set up PVOutput), to read your system data. Your system ID and API key are sent to PVOutput over HTTPS.
  • Your inverter on your home network (only if you enter its address in Settings): the Smart Dongle of a Huawei inverter, or a SunSpec inverter such as SolarEdge, SMA or Fronius, to read live production with Modbus TCP. This connection never leaves your home network, and SunWatt only reads.
  • apidatos.ree.es (Red Eléctrica), for the regulated PVPC price in Spain.
  • api.energy-charts.info (Energy-Charts, Fraunhofer ISE, licence CC BY 4.0), for day-ahead wholesale prices in Portugal, France, Germany & Luxembourg, Austria, Belgium, the Netherlands and North Italy.

These servers receive normal network requests (such as your IP address) as any website does. We do not control them. SunWatt sends them no device identifier or analytics data, and no account other than the one you set up for that service.

Data on your device

Your settings (country, widget options, kiosk link, SolarEdge or PVOutput ID and API key) and the last data received stay on your device. They are shared only between the app and its widgets through an App Group on the same device, and with your own paired Apple Watch so its app and complications work. They are never sent to us. We cannot see them.

The FusionSolar kiosk link

The kiosk link gives read-only access to your plant data. Anyone who has the link can see that data. Share it with care. You can turn the kiosk off in the FusionSolar portal at any time, and the link stops working.

SolarEdge and PVOutput API keys

An API key gives access to your plant data (on PVOutput, the same key can also add data to your system). SunWatt uses it only to read your data, and sends it only to that provider. Anyone who has the key can use it, so keep it private. You can revoke it at any time in the provider's portal: in SolarEdge under Admin > Site Access > API Access, in PVOutput under Settings > API Settings (turn off API access or generate a new key). The old key stops working.

FusionSolar API account

The user name and system code of a FusionSolar API account give access to your plant data. SunWatt uses them only to read your data, keeps the system code in the keychain of your device, and sends them only to the FusionSolar server you enter (a fusionsolar.huawei.com address). Your installer can change the system code or delete the account in FusionSolar at any time.

Tracking, analytics, advertising

None. There are no third-party SDKs for analytics or ads, and no tracking across apps or websites.

Children

The app collects no data from anyone, including children.

Changes

If this policy changes, the new version will be published on this page with a new date.

Not affiliated

SunWatt is not affiliated with Huawei, SolarEdge, PVOutput, Red Eléctrica or Fraunhofer ISE.

Conexiones de red

La app solo se conecta a estos servidores para obtener los datos que muestra:

  • El servidor de Huawei FusionSolar indicado en el enlace Kiosk que pegues (solo si añades un enlace), para leer los datos de tu planta.
  • El servidor de Huawei FusionSolar que introduzcas para una cuenta de API de FusionSolar (solo si configuras una, una dirección de fusionsolar.huawei.com), para leer los datos de tu planta. Tu nombre de usuario y tu código del sistema se envían a ese servidor por HTTPS.
  • monitoringapi.solaredge.com (la API oficial de monitorización de SolarEdge, solo si configuras SolarEdge), para leer los datos de tu planta. El ID del sitio y tu clave API se envían a SolarEdge por HTTPS.
  • pvoutput.org (la API de PVOutput, solo si configuras PVOutput), para leer los datos de tu sistema. El ID de tu sistema y tu clave API se envían a PVOutput por HTTPS.
  • Tu inversor en la red de tu casa (solo si introduces su dirección en Ajustes): el Smart Dongle de un inversor Huawei o un inversor SunSpec, como los de SolarEdge, SMA o Fronius, para leer la producción en directo con Modbus TCP. Esta conexión nunca sale de la red de tu casa, y SunWatt solo lee datos.
  • apidatos.ree.es (Red Eléctrica), para el precio PVPC regulado en España.
  • api.energy-charts.info (Energy-Charts, Fraunhofer ISE, licencia CC BY 4.0), para los precios del mercado mayorista (day-ahead) de Portugal, Francia, Alemania y Luxemburgo, Austria, Bélgica, Países Bajos y norte de Italia.

Estos servidores reciben peticiones de red normales (por ejemplo tu dirección IP), como cualquier sitio web. No los controlamos. SunWatt no envía ningún identificador de dispositivo ni datos de analítica, ni ninguna cuenta distinta de la que configuraste para ese servicio.

Datos en tu dispositivo

Tus ajustes (país, opciones de widgets, enlace Kiosk, ID y clave API de SolarEdge o PVOutput) y los últimos datos recibidos se quedan en tu dispositivo. Solo los comparten la app y sus widgets mediante un App Group en el mismo dispositivo, y tu propio Apple Watch emparejado para que funcionen su app y sus complicaciones. Nunca se nos envían. Nosotros no podemos verlos.

El enlace Kiosk de FusionSolar

El enlace Kiosk da acceso de solo lectura a los datos de tu planta. Quien tenga el enlace puede ver esos datos. Compártelo con cuidado. Puedes desactivar el Kiosk en el portal de FusionSolar cuando quieras y el enlace dejará de funcionar.

Claves API de SolarEdge y PVOutput

Una clave API da acceso a los datos de tu planta (en PVOutput, la misma clave también permite añadir datos a tu sistema). SunWatt solo la usa para leer tus datos y solo la envía a ese proveedor. Quien tenga la clave puede usarla, así que guárdala bien. Puedes revocarla cuando quieras en el portal del proveedor: en SolarEdge, en Admin > Site Access > API Access; en PVOutput, en Settings > API Settings (desactiva el acceso API o genera una clave nueva). La clave antigua dejará de funcionar.

Cuenta de API de FusionSolar

El nombre de usuario y el código del sistema de una cuenta de API de FusionSolar dan acceso a los datos de tu planta. SunWatt los usa solo para leer tus datos, guarda el código del sistema en el llavero de tu dispositivo y los envía únicamente al servidor de FusionSolar que introduzcas (una dirección de fusionsolar.huawei.com). Tu instalador puede cambiar el código del sistema o eliminar la cuenta en FusionSolar en cualquier momento.

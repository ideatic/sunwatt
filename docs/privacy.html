Privacy Policy

App: SunWatt (iPhone, iPad, Mac, Apple Watch, Android, Wear OS). Last updated: 22 October 2026.

Short version. SunWatt has no account, no tracking, no analytics and no ads. Nothing is sent to the developer.

Who we are

SunWatt is published by Ideatic Development, S.L.U. (Spain). Contact: contacto@ideatic.net.

Data we collect

None. We do not collect, receive or store any personal data. We have no servers for the app. On Google Play, the Data safety section of SunWatt says "No data collected".

Network connections

The app contacts only these servers, to get the data it shows:

  • The Huawei FusionSolar server named in the kiosk link you paste (only if you add a link), to read your plant data.
  • The Huawei FusionSolar server you enter for a FusionSolar API account (only if you set one up, a fusionsolar.huawei.com address), to read your plant data. Your user name and system code are sent to it over HTTPS.
  • monitoringapi.solaredge.com (the official SolarEdge Monitoring API, only if you set up SolarEdge), to read your plant data. Your site ID and API key are sent to SolarEdge over HTTPS.
  • pvoutput.org (the PVOutput API, only if you set up PVOutput), to read your system data. Your system ID and API key are sent to PVOutput over HTTPS.
  • Your inverter on your home network (only if you enter its address in Settings): the Smart Dongle of a Huawei inverter or a SunSpec inverter such as SolarEdge, SMA or Fronius (Modbus TCP), or a Fronius inverter through its Solar API (HTTP), to read live production. This connection never leaves your home network, and SunWatt only reads. On Android, "Find inverter" checks the addresses of your own Wi-Fi network for an inverter, and only when you tap it.
  • apidatos.ree.es (Red Eléctrica), for the regulated PVPC price in Spain.
  • api.energy-charts.info (Energy-Charts, Fraunhofer ISE, licence CC BY 4.0), for day-ahead wholesale prices in Portugal, France, Germany & Luxembourg, Austria, Belgium, the Netherlands and North Italy.

A Wear OS watch gets the same data itself over its own connection, from the same servers.

These servers receive normal network requests (such as your IP address) as any website does. We do not control them. SunWatt sends them no device identifier or analytics data, and no account other than the one you set up for that service.

Data on your device

Your settings (country, widget options, kiosk link, SolarEdge or PVOutput ID and API key) and the last data received stay on your device. They are never sent to us. We cannot see them.

The kiosk link, the API keys and the FusionSolar system code are stored encrypted: in the keychain on Apple devices, and with a key from the Android Keystore on Android and Wear OS.

On Apple devices, the app and its widgets share the settings through an App Group on the same device, and the app sends them to your own paired Apple Watch so its app and complications work.

On Android, the app, its widgets and its Quick Settings tiles share the settings on the same phone. The app sends them to your own paired Wear OS watch through the encrypted Wear OS connection (Google Play services), and the watch stores the secrets encrypted with its own Android Keystore. SunWatt data is not included in Android backups. To refresh the widgets, the app asks Android to run a background task (WorkManager) about every 15 minutes, only when a network is available. Apart from network access, the app needs no permissions: no location, no contacts, no notifications.

The FusionSolar kiosk link

The kiosk link gives read-only access to your plant data. Anyone who has the link can see that data. Share it with care. You can turn the kiosk off in the FusionSolar portal at any time, and the link stops working.

SolarEdge and PVOutput API keys

An API key gives access to your plant data (on PVOutput, the same key can also add data to your system). SunWatt uses it only to read your data, and sends it only to that provider. Anyone who has the key can use it, so keep it private. You can revoke it at any time in the provider's portal: in SolarEdge under Admin > Site Access > API Access, in PVOutput under Settings > API Settings (turn off API access or generate a new key). The old key stops working.

FusionSolar API account

The user name and system code of a FusionSolar API account give access to your plant data. SunWatt uses them only to read your data, keeps the system code encrypted on your device (see above), and sends them only to the FusionSolar server you enter (a fusionsolar.huawei.com address). Your installer can change the system code or delete the account in FusionSolar at any time.

Tracking, analytics, advertising

None. There are no third-party SDKs for analytics or ads, and no tracking across apps or websites.

Children

The app collects no data from anyone, including children.

Changes

If this policy changes, the new version will be published on this page with a new date.

Not affiliated

SunWatt is not affiliated with Huawei, SolarEdge, PVOutput, Red Eléctrica or Fraunhofer ISE.

Conexiones de red

La app solo se conecta a estos servidores para obtener los datos que muestra:

  • El servidor de Huawei FusionSolar indicado en el enlace Kiosk que pegues (solo si añades un enlace), para leer los datos de tu planta.
  • El servidor de Huawei FusionSolar que introduzcas para una cuenta de API de FusionSolar (solo si configuras una, una dirección de fusionsolar.huawei.com), para leer los datos de tu planta. Tu nombre de usuario y tu código del sistema se envían a ese servidor por HTTPS.
  • monitoringapi.solaredge.com (la API oficial de monitorización de SolarEdge, solo si configuras SolarEdge), para leer los datos de tu planta. El ID del sitio y tu clave API se envían a SolarEdge por HTTPS.
  • pvoutput.org (la API de PVOutput, solo si configuras PVOutput), para leer los datos de tu sistema. El ID de tu sistema y tu clave API se envían a PVOutput por HTTPS.
  • Tu inversor en tu red de casa (solo si introduces su dirección en Ajustes): el Smart Dongle de un inversor Huawei o un inversor SunSpec, como los de SolarEdge, SMA o Fronius (Modbus TCP), o un inversor Fronius a través de su Solar API (HTTP), para leer la producción en directo. Esta conexión nunca sale de la red de tu casa, y SunWatt solo lee datos. En Android, "Buscar inversor" busca un inversor en las direcciones de tu propia red Wi-Fi. Solo lo hace cuando tocas el botón.
  • apidatos.ree.es (Red Eléctrica), para el precio PVPC regulado en España.
  • api.energy-charts.info (Energy-Charts, Fraunhofer ISE, licencia CC BY 4.0), para los precios del mercado mayorista (day-ahead) de Portugal, Francia, Alemania y Luxemburgo, Austria, Bélgica, Países Bajos y norte de Italia.

Un reloj con Wear OS obtiene los mismos datos por sí mismo, con su propia conexión y desde los mismos servidores.

Estos servidores reciben peticiones de red normales (por ejemplo tu dirección IP), como cualquier sitio web. No los controlamos. SunWatt no envía ningún identificador de dispositivo ni datos de analítica, ni ninguna cuenta distinta de la que configuraste para ese servicio.

Datos en tu dispositivo

Tus ajustes (país, opciones de widgets, enlace Kiosk, ID y clave API de SolarEdge o PVOutput) y los últimos datos recibidos se quedan en tu dispositivo. Nunca se nos envían. Nosotros no podemos verlos.

El enlace Kiosk, las claves API y el código del sistema de FusionSolar se guardan cifrados: en el llavero de los dispositivos Apple, y con una clave del Android Keystore en Android y Wear OS.

En dispositivos Apple, la app y sus widgets comparten los ajustes mediante un App Group en el mismo dispositivo. La app también los envía a tu propio Apple Watch emparejado, para que funcionen su app y sus complicaciones.

En Android, la app, sus widgets y sus mosaicos de Ajustes rápidos comparten los ajustes en el mismo teléfono. La app los envía a tu propio reloj con Wear OS emparejado, por la conexión cifrada de Wear OS (Servicios de Google Play). El reloj guarda los secretos cifrados con su propio Android Keystore. Los datos de SunWatt no se incluyen en las copias de seguridad de Android. Para actualizar los widgets, la app pide a Android ejecutar una tarea en segundo plano (WorkManager) cada 15 minutos aproximadamente, solo cuando hay red disponible. Aparte del acceso a la red, la app no necesita ningún permiso: ni ubicación, ni contactos, ni notificaciones.

El enlace Kiosk de FusionSolar

El enlace Kiosk da acceso de solo lectura a los datos de tu planta. Quien tenga el enlace puede ver esos datos. Compártelo con cuidado. Puedes desactivar el Kiosk en el portal de FusionSolar cuando quieras y el enlace dejará de funcionar.

Claves API de SolarEdge y PVOutput

Una clave API da acceso a los datos de tu planta (en PVOutput, la misma clave también permite añadir datos a tu sistema). SunWatt solo la usa para leer tus datos y solo la envía a ese proveedor. Quien tenga la clave puede usarla, así que guárdala bien. Puedes revocarla cuando quieras en el portal del proveedor: en SolarEdge, en Admin > Site Access > API Access; en PVOutput, en Settings > API Settings (desactiva el acceso API o genera una clave nueva). La clave antigua dejará de funcionar.

Cuenta de API de FusionSolar

El nombre de usuario y el código del sistema de una cuenta de API de FusionSolar dan acceso a los datos de tu planta. SunWatt los usa solo para leer tus datos, guarda el código del sistema cifrado en tu dispositivo (ver arriba) y los envía únicamente al servidor de FusionSolar que introduzcas (una dirección de fusionsolar.huawei.com). Tu instalador puede cambiar el código del sistema o eliminar la cuenta en FusionSolar en cualquier momento.

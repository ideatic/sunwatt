# SunWatt for Android

Planned. This folder will hold the Android app (Gradle project).

Read the top-level `AGENTS.md` and `DECISIONS.md` first. The rules there (secrets, rate limits, time zones, translations, attribution) apply here too. The Apple app in `../apple/` is the reference for behaviour: providers, price sources, parsers and their test fixtures (`../apple/Packages/SunWattKit/Tests/SunWattKitTests/Fixtures/`).

Secrets and local test data go in the top-level `../private/` (git-ignored), never in this folder.
